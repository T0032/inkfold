# Inkfold — โต๊ะเขียนนิยาย (เวอร์ชัน 1.0.0)

Inkfold คือโปรแกรมช่วยเขียนนิยายรุ่นใหม่ที่แยกออกมาจาก "โต๊ะนักเขียน" ระบบทุกอย่างเหมือนเดิม แต่เพิ่มภาพและอนิเมชันให้สวยงามขึ้น:

- **เปิดโปรแกรม:** หนังสือปกแข็งค่อย ๆ ลอยขึ้น ปกเปิดออก หน้ากระดาษพลิกไปถึงกลางเล่ม แล้วซูมเข้าสู่โต๊ะเขียน (ประมาณ 4.5 วินาที คลิกหรือกด Esc เพื่อข้ามได้)
- **เปิดนิยายแต่ละเรื่อง:** เปิดเป็นหนังสือเล่มเล็กตามสีหรือรูปปกของเรื่องนั้น (แบบสั้น ประมาณ 2.5 วินาที)
- **ตกแต่ง:** พื้นหลังมีผิวกระดาษ หน้าเขียนมีมุมกระดาษพับ การ์ดนิยายดูเหมือนหนังสือ (มีสันปกและริบบิ้นคั่น เอียงเล็กน้อยเมื่อชี้) มีภาพประกอบในหน้าว่าง และเปลี่ยนหน้าแบบนุ่มนวล
- **ปิดอนิเมชันได้ที่ ⚙ ตั้งค่า → อนิเมชันและเอฟเฟกต์** ในหน้าเดียวกันมีปุ่ม "ดูอนิเมชันอีกครั้ง"

## แยกจากของเก่าอย่างไร
- อยู่คนละโฟลเดอร์ (`D:\Inkfold`) และเก็บข้อมูลในเบราว์เซอร์คนละที่กับโต๊ะนักเขียน งานของสองโปรแกรมจึงไม่ปนกัน
- **ย้ายงานจากโต๊ะนักเขียนมาใช้ได้:** ในโต๊ะนักเขียนกด "สำรองทั้งคลัง" แล้วใน Inkfold กด "นำเข้า"

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวโปรแกรมทั้งหมด |
| `manifest.webmanifest` | ข้อมูลแอปสำหรับ "ติดตั้งเป็นแอป" |
| `sw.js` | ใช้งานออฟไลน์ (เมื่อเปิดผ่านเว็บ https) |
| `icons/` | ไอคอนรูปหนังสือปกแข็ง |

## นำขึ้น GitHub (ขั้นตอนเดียวกับโต๊ะนักเขียน)
1. สร้าง repository ใหม่ชื่อ `inkfold` แบบ **Public**
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ไฟล์ข้างใน ไม่ใช่ลากตัวโฟลเดอร์)
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
4. ลิงก์จะเป็น `https://ชื่อผู้ใช้.github.io/inkfold/`

## ออกเวอร์ชันใหม่
แก้ `APP_VERSION` ใน `index.html` และ `VERSION` ใน `sw.js` ให้ตรงกันทุกครั้ง
