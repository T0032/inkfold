# Inkfold — โต๊ะเขียนนิยาย (เวอร์ชัน 1.3.1)

Inkfold คือโปรแกรมช่วยเขียนนิยายภาษาไทยที่ทำงานในเบราว์เซอร์ ใช้งานออฟไลน์ได้ ติดตั้งเป็นแอปได้ และเก็บงานทั้งหมดไว้ในเครื่องของผู้ใช้ ไม่มีการส่งเนื้อหาออกไปที่ใด

**เปิดใช้งาน:** https://t0032.github.io/inkfold/

## ความสามารถหลัก
| ระบบ | รายละเอียด |
|---|---|
| เขียนต้นฉบับ | แถบเครื่องมือแบบ Word, โหมดโฟกัสและเต็มจอ, Typewriter Scrolling, แผงข้อมูลอ้างอิงข้างหน้าเขียน, เติมชื่ออัตโนมัติ |
| โครงสร้างเล่ม | บท → ฉาก, ลากเรียงบท, คอร์กบอร์ดฉาก (ลากย้ายฉากข้ามบทได้) |
| วางพล็อต | โครงเรื่อง 3 องก์, ปมเรื่อง, กระดานอิสระ, เส้นเวลา |
| Story Bible | ตัวละคร, ผังความสัมพันธ์, สถานที่, แผนที่ปักหมุด, คำศัพท์และกฎของโลก, ภาพประกอบ |
| ตรวจทาน | ตรวจคำซ้ำ, ค้นหาและแทนที่ทั้งเรื่อง, ดูว่าชื่อปรากฏในบทไหนบ้าง |
| เป้าหมายและสถิติ | นับคำและตัวอักษรภาษาไทย, เป้ารายวันและทั้งเล่ม, Streak, กราฟ 14 วัน |
| ความปลอดภัยของข้อมูล | บันทึกอัตโนมัติ, ออฟไลน์, ประวัติเวอร์ชัน, ถังขยะ 30 วัน, บันทึกลงไฟล์อัตโนมัติ |
| ส่งออก / นำเข้า | DOCX, PDF, EPUB, Markdown, TXT, คัดลอกสำหรับเว็บนิยาย, นำเข้า Word/.txt/.md และฟอนต์ |

## เวอร์ชัน 1.3.1
- แก้ปัญหาชี้หนังสือบนชั้นแล้วคลิกเข้าไปในนิยายไม่ได้ (หน้าปกที่หมุนแบบ 3D ไม่รับการคลิก)

## มีอะไรใหม่ในเวอร์ชัน 1.3.0
- **Typewriter Scrolling:** บรรทัดที่กำลังพิมพ์อยู่กลางจอเสมอ (ปุ่ม ⇔ ในแถบเครื่องมือ หรือ ⚙ ตั้งค่า → การเขียน)
- **คัดลอกสำหรับเว็บนิยาย:** ปุ่ม "เว็บนิยาย" ในแถบเครื่องมือ คัดลอกตอนนี้ไปวางใน Dek-D, ReadAWrite, Fictionlog, Joylada ได้ทันที ตั้งได้ว่าจะใส่ชื่อตอน, เว้นบรรทัดระหว่างย่อหน้า, ย่อหน้าด้วยการเว้นวรรค, คงตัวหนา/เอียง และเลือกตัวคั่นฉาก
- **ตรวจคำซ้ำ:** ปุ่ม ✓ ข้างหัวบท หรือแท็บ "คำซ้ำ" ในแผงข้าง บอกคำที่ใช้ซ้ำถี่ในระยะใกล้กัน (ตั้งระยะและจำนวนครั้งได้) คลิกคำแล้วไฮไลต์ในเนื้อหา ไม่แก้ต้นฉบับ
- **ฉากในบท:** แทรก → "เริ่มฉากใหม่" เพื่อแบ่งฉาก รายการบทด้านซ้ายกางดูฉากได้ ตั้งชื่อฉากได้ในแท็บโน้ตบท
- **คอร์กบอร์ดฉาก:** กระดานวางแผน → แท็บ "คอร์กบอร์ดฉาก" แสดงทุกฉากเป็นการ์ดเรียงตามบท ใส่ชื่อ สรุป และสถานะได้ ลาก ⠿ เพื่อย้ายฉาก (ข้ามบทได้ เนื้อหาย้ายตามจริง และเก็บเวอร์ชันก่อนย้ายไว้ให้)
- **แผนที่:** ฉากและสถานที่ → "แผนที่" อัปโหลดรูปแผนที่ ปักหมุดสถานที่ ลากย้ายหมุด คลิกหมุดดูข้อมูล และมีได้หลายแผนที่
- **ภาพประกอบ:** ตัวละครและสถานที่ใส่รูปได้หลายรูป ตั้งรูปหลักได้ (รูปหลักของสถานที่แสดงในรายการด้วย)

## เวอร์ชัน 1.2.0
- **ซ่อนแถบเมนู:** ปุ่ม ▯ มุมขวาบน หรือกด **Ctrl+\\** เพื่อทำงานเต็มพื้นที่ (ปุ่มข้าง ๆ เป็นโหมดเต็มจอ) และซ่อนรายการบทได้ด้วยปุ่ม ‹ ในหน้าเนื้อหาบท
- **ย้ายแถบเมนูไปด้านบนแบบ Word:** ⚙ ตั้งค่า → หน้าตา → ตำแหน่งแถบเมนู
- **แถบเครื่องมือแบบ Word:**
  - รูปแบบย่อหน้า (ปกติ / หัวเรื่อง 1–3 / คำพูด), เลือกฟอนต์, ขนาดตัวอักษร
  - ตัวหนา / เอียง / ขีดเส้นใต้ / **ขีดฆ่า**, **สีตัวอักษร**, **ไฮไลต์**, **ล้างรูปแบบ**
  - จัดแนว, **รายการจุดและตัวเลข**, **แทรก** (ตัวคั่นฉาก เส้นคั่น วันที่ อักขระพิเศษ), **พิมพ์บทนี้**
  - แถบสถานะบอกเวลาอ่านโดยประมาณ
  - รูปแบบเหล่านี้ติดไปในไฟล์ Word / PDF / EPUB ที่ส่งออกด้วย
- **นำเข้าไฟล์ Word (.docx), .txt, .md ลงในนิยาย:** ปุ่ม ⤒ ในแถบเครื่องมือ ถ้าไฟล์มีหัวเรื่อง (Heading 1) จะแยกเป็นหลายบทให้อัตโนมัติ
- **นำเข้าฟอนต์ที่ดาวน์โหลดมาเอง:** ⚙ ตั้งค่า → การเขียน → นำเข้าฟอนต์ (.ttf .otf .woff .woff2)
- **ตั้งค่าการเขียนเพิ่ม:** ย่อหน้าบรรทัดแรกอัตโนมัติ, ตรวจคำสะกด, ซ่อน/แสดงแถบเครื่องมือ
- **ชั้นหนังสือ 10 เล่มต่อชั้น:** เกินแล้วขึ้นชั้นใหม่ต่อไปเรื่อย ๆ
- **ชี้ที่หนังสือ:** เล่มดึงออกจากชั้น หมุนหันหน้าปกออกมา พร้อมป้ายชื่อเรื่องด้านบน (มีปุ่มแก้ไข/ลบในป้าย)
- **สีสันหนังสือตามรูปปก:** อัปโหลดรูปปกหรือเลือกปกสำเร็จรูปแล้ว สีสันจะเปลี่ยนตามโทนของปกอัตโนมัติ
- แก้ไฟล์ Word ที่ส่งออกให้ลำดับคำสั่งจัดรูปแบบถูกตามมาตรฐาน เพื่อให้ Word เปิดได้โดยไม่เตือน

## เวอร์ชัน 1.1.0
- **เสียงพลิกหน้ากระดาษ:** เสียงเปิดปกและพลิกหน้าระหว่างอนิเมชัน และเสียงเบา ๆ ตอนเปลี่ยนบท สร้างด้วยโค้ดทั้งหมด ไม่มีไฟล์เสียง ไม่ติดลิขสิทธิ์
- **แสงและเงาตอนพลิกหน้า:** หน้ากระดาษสว่างและมืดตามมุม มีเงาทอดลงบนหน้าถัดไป และมีแสงวาบบนปกตอนหนังสือปรากฏ
- **ชั้นหนังสือ:** หน้าคลังแสดงนิยายเป็นสันหนังสือบนชั้นไม้ ความหนาของเล่มเพิ่มตามจำนวนคำ ชี้แล้วเล่มจะดึงออกมา (สลับกลับเป็นแบบการ์ดได้)
- **ไอคอนเมนูวาดมือ:** ไอคอนเมนูหลักเป็นลายเส้นแบบวาดมือ (เปลี่ยนกลับเป็นแบบเรียบได้)
- **ปกนิยายสำเร็จรูป 8 แบบ:** แฟนตาซี โรแมนซ์ สืบสวน ไซไฟ สยองขวัญ ดราม่า กำลังภายใน และชีวิตประจำวัน ใส่ชื่อเรื่องให้อัตโนมัติ (ปุ่ม ✎ ข้างชื่อนิยาย → "ปกสำเร็จรูป")
- **หน้าตั้งค่าใหม่:** ปุ่ม ⚙ ตั้งค่า มุมขวาบนทุกหน้า รวมการตั้งค่าทุกอย่างไว้ 5 หมวด ได้แก่
  - **หน้าตา:** โทนสี, รูปแบบไอคอน, รูปแบบหน้าคลัง
  - **การเขียน:** แบบและขนาดตัวอักษร, ระยะห่างบรรทัด, ความกว้างหน้ากระดาษ, เปิด/ปิดการเติมชื่ออัตโนมัติ
  - **อนิเมชันและเสียง:** เปิด/ปิดอนิเมชันแยกส่วน, ความเร็ว ช้า/ปกติ/เร็ว, เปิด/ปิดเสียง, ระดับเสียง, ลองฟังเสียง
  - **ข้อมูลและการสำรอง:** ที่เก็บข้อมูล, บันทึกลงไฟล์อัตโนมัติ, ความถี่การเตือนสำรอง, สำรอง/นำเข้า/ถังขยะ
  - **เกี่ยวกับ:** เวอร์ชัน, ดูอนิเมชันอีกครั้ง, คืนค่าการตั้งค่าเริ่มต้น

> หมายเหตุเรื่องเสียง: ตอนเปิดโปรแกรมครั้งแรก เบราว์เซอร์มักไม่ให้เล่นเสียงจนกว่าผู้ใช้จะคลิกหน้าเว็บหนึ่งครั้ง (เป็นกฎของเบราว์เซอร์) หลังจากนั้นเสียงจะเล่นตามปกติ เช่นตอนเปิดนิยาย

## จากเวอร์ชัน 1.0.0
- **เปิดโปรแกรม:** หนังสือปกแข็งค่อย ๆ ลอยขึ้น ปกเปิดออก หน้ากระดาษพลิกไปถึงกลางเล่ม แล้วซูมเข้าสู่โต๊ะเขียน (คลิกหรือกด Esc เพื่อข้าม)
- **เปิดนิยายแต่ละเรื่อง:** เปิดเป็นหนังสือเล่มเล็กตามสีหรือรูปปกของเรื่องนั้น
- **ตกแต่ง:** ผิวกระดาษ มุมกระดาษพับ ภาพประกอบในหน้าว่าง และเปลี่ยนหน้าแบบนุ่มนวล

## แยกจากโต๊ะนักเขียนอย่างไร
- อยู่คนละโฟลเดอร์ (`D:\Inkfold`) และเก็บข้อมูลในเบราว์เซอร์คนละที่ งานของสองโปรแกรมจึงไม่ปนกัน
- **ย้ายงานจากโต๊ะนักเขียนมาใช้ได้:** ในโต๊ะนักเขียนกด "สำรองทั้งคลัง" แล้วใน Inkfold กด "นำเข้า"

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวโปรแกรมทั้งหมด |
| `manifest.webmanifest` | ข้อมูลแอปสำหรับ "ติดตั้งเป็นแอป" |
| `sw.js` | ใช้งานออฟไลน์ (เมื่อเปิดผ่านเว็บ https) |
| `icons/` | ไอคอนรูปหนังสือปกแข็ง |
| `เวอร์ชันเก่า/` | สำเนาเวอร์ชันก่อนหน้า — **ไม่ต้องอัปโหลดขึ้น GitHub** |

## อัปเดตบน GitHub
1. เข้า repo `inkfold` → **Add file → Upload files**
2. ลาก `index.html`, `sw.js` และ `README.md` ไปวางทับของเดิม แล้วกด **Commit changes**
3. รอ 1–2 นาที แล้วเปิด https://t0032.github.io/inkfold/ (ถ้ายังเห็นของเก่า ให้รีเฟรช 1–2 ครั้ง)

## ออกเวอร์ชันใหม่
แก้ `APP_VERSION` ใน `index.html` และ `VERSION` ใน `sw.js` ให้ตรงกันทุกครั้ง
